Ufuncs#

Las ufuncs (universal functions) son funciones especiales de numpy que permiten operar sobre objetos ndarray de manera vectorizada o element-wise (elemento por elemento). Existen de dos tipos, unitarias y binarias, dependiendo de la cantidad de operandos.

Important

No todas las funciones en numpy son ufunc. Para una lista completa de las funciones ufunc visitar la documetación de numpy. En esta sitio las ufunc se pueden encontrar principalmente en las siguientes secciones.

  • Matemáticas y numéricas.

  • Operadores.

  • Información.

Tip

Las funciones ufunc de numpy también se pueden usar en los objetos de pandas como DataFrame y Series.

Para saber si una función es ufunc usar:

# Retorna el tipo de una función
type(function_name) # -> Debe retornar <class ‘numpy.ufunc’>

# Veririfacr el tipo de una función
type(function_name) == np.ufunc # Retorna True o False

Párametros comunes#

Las funciones ufunc comparten varios parámetros. A continuación se explicarán los más comunes, para una lista completa visitar la documentación de numpy.

  • where - array-like de bool (mask): Array booleano, para indicar en qué elementos sí aplicar la función y cuáles dejar intactos.

  • dtype - dtype: Define el tipo de dato que deben de tener los elementos retornados.

  • out - object de tipo ndarray o None: Es para indicar el objeto donde se almacenará el resultado, es posible poner el mismo objeto en el que se está haciendo la operación para que sea in-place.


Ufuncs personalizadas#

Para crear una ufuncs personalizadas, primero se debe definir una función de manera tradicional o utilizar una built-in, posteriormente se debe de agregar la función a la librería ufunc de numpy con frompyfunc().

numpy.frompyfunc(func, /, nin, nout, *[, identity])

  • function - function: Es el nombre de una función de Python.

  • nin - int: Número de argumentos de ingreso.

  • nout - int: Número de objetos retornados por la función.

# Definir función
def my_func(params):
    # function body

# Agregar función a la librerica ufuc    
my_ufunc = np.frompyfunc(my_func)

Ejemplo

En este ejemplo se convertirá la función str.center(string, width[, fillchar) en una ufunc.

# Importar numpy
import numpy as np

# Convertir función a ufunc
ucenter = np.frompyfunc(str.center, 3, 1)

# Usar función
ucenter(np.array(["abc", "A", "12345"]), 7, "*")

array(['**abc**', '***A***', '*12345*'], dtype=object)

Lo anterior también se habría logrado usando:

# Usando el metodo en cada cadena
np.array(["abc".center(7, "*"), "A".center(7, "*"), "12345".center(7, "*")])

# Aplicando map
np.array([*map(str.center, ["abc", "A", "12345"], [7]*3, ['*']*3)])

Atributos#

Atributos de las funciones ufunc.

Atributo

Descripción

__doc__

Cadena de documentación para cada ufunc.

__name__

El nombre de la ufunc.

ufunc.identity

El elemento identidad de la ufunc, si tiene (identidad como el concepto matemático de elemento identidad en operaciones).

ufunc.nargs

El número de argumentos.

ufunc.nin

El número de entradas.

ufunc.nout

El número de salidas.

ufunc.ntypes

El número de tipos.

ufunc.signature

Definición de los elementos centrales sobre los que opera una ufunc generalizada.

ufunc.types

Retorna un ´list´ con tipos agrupados entrada->salida.

Métodos#

Métodos de las funciones ufunc.

Método

Descripción

ufunc.accumulate(array[, axis, dtype, out])

Acumula el resultado de aplicar el operador a todos los elementos. Equivale a hacer cálculos acumulados.

ufunc.at(a, indices[, b])

Realiza una operación in-place sin búfer en a para los elementos especificados por indices. Un mismo índice puede aparecer múltiples veces en indices y la operación se aplicaría ese mismo número de veces a ese elemento.

ufunc.outer(A, B, /, **kwargs)

Aplica la operación ufunc a todos los pares (a, b) con a en A y b en B (en el producto cartesiando de A y B).

ufunc.reduce(array[, axis, dtype, out, …])

Reduce la dimensión de ´array´ a uno (vector), aplicando la ufunc a lo largo de un eje. Equivale a hacer aggregates.

ufunc.reduceat(array, indices[, axis, …])

Realiza una reducción (local) con cortes especificados en un solo eje.

Ejemplos#

A continuación se presentan ejemplos de algunos métodos seleccionados (para más ejemplos presionar sobre el nombre de cada método en la tabla de métodos para dirigirse a la documentación de numpy).

# Definir el array
a = np.array([1, 2, 3])

# Ejemplo de accumulate
print("Acumulado: ", np.add.accumulate(a), end='\n'*2)

# Ejemplo de reduce
print("Aggregate: ", np.add.reduce(a), end='\n'*2)

# Ejemplo de outer
print("Producto cartesiano: \n", np.power.outer(a, a), end='\n'*2)

Acumulado:  [1 3 6]

Aggregate:  6

Producto cartesiano: 
 [[ 1  1  1]
 [ 2  4  8]
 [ 3  9 27]]
