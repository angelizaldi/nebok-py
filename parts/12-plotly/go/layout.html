Layout#

Define la apariencia y estructura del gráfico, como títulos, ejes, leyendas y márgenes. En esta sección se revisan tanto la clase Layout como el módulo layout. Ambos se relacionan ya que una instancia de Layout se define con las clases implementadas en el módulo layout.

Warning

El módulo layout tiene múltiples submódulos que se pueden revisar en la documentación. Notar que el módulo se divide en múltiples submódulos, y estos a su vez estos pueden tener otros submódulos.

En las clases documentadas en este sitio que tienen submódulos se enlistarán sus submódulos.

Layout#

Objeto que establece el estilo de una figura.

Constructor

Descripción

go.Layout(arg=None, …)

Construye un nuevo objeto de diseño.

plotly.graph_object.Layout(): Objeto que establece el estilo de una figura.

# Sintaxis de llamada
go.Layout(*args, , **kwargs)

Parámetros:

  • legend - layout.Legend o dict: Propiedades de la leyenda de la gráfica.

  • xaxis, yaxis - layout.XAxis, layout.Yaxis o dict: Propiedades de los ejes x y y respectivamente.

  • title - layout.Title o dict: Propiedades del título de la gráfica.

  • annotations - tuple de layout.Annotation o dict: Instancias o dict con propiedades compatibles.

Configura el eje x del gráfico (etiquetas, rango, escala, etc.).

Important

El módulo asociado a esta clase es layout.xaxis y sus submódulos son los siguientes:

  • xaxis.rangeselector.

  • xaxis.rangeslider.

  • xaxis.title


Atributos de XAxis#

Atributos de la clase XAxis.

Caution

Las descripciones de los atributos de esta clase están en inglés.

Atributo

Descripción

anchor

If set to an opposite-letter axis id (e.g. x2, y), this axis is bound to the corresponding opposite-letter axis.

automargin

Determines whether long tick labels automatically grow the figure margins.

autorangeoptions

The autorangeoptions property is an instance of Autorangeoptions.

autorange

Determines whether or not the range of this axis is computed in relation to the input data.

autotickangles

When tickangle is set to “auto”, it will be set to the first angle in this array that is large enough to prevent label overlap.

autotypenumbers

Using “strict” a numeric string in trace data is not converted to a number.

calendar

Sets the calendar system to use for range and tick0 if this is a date axis.

categoryarraysrc

Sets the source reference on Chart Studio Cloud for categoryarray.

categoryarray

Sets the order in which categories on this axis appear.

categoryorder

Specifies the ordering logic for the case of categorical variables.

color

Sets default for all colors associated with this axis all at once: line, font, tick, and grid colors.

constraintoward

If this axis needs to be compressed (either due to its own scaleanchor and scaleratio or those of the other axis), determines which direction we push the originally specified plot area.

constrain

If this axis needs to be compressed (either due to its own scaleanchor and scaleratio or those of the other axis), determines how that happens: by increasing the “range”, or by decreasing the “domain”.

dividercolor

Sets the color of the dividers. Only has an effect on “multicategory” axes.

dividerwidth

Sets the width (in px) of the dividers. Only has an effect on “multicategory” axes.

domain

Sets the domain of this axis (in plot fraction).

dtick

Sets the step in-between ticks on this axis.

exponentformat

Determines a formatting rule for the tick exponents.

fixedrange

Determines whether or not this axis is zoom-able.

gridcolor

Sets the color of the grid lines.

griddash

Sets the dash style of lines.

gridwidth

Sets the width (in px) of the grid lines.

hoverformat

Sets the hover text formatting rule using d3 formatting mini-languages which are very similar to those in Python.

insiderange

Could be used to set the desired inside range of this axis

labelalias

Replacement text for specific tick or hover labels.

layer

Sets the layer on which this axis is displayed.

linecolor

Sets the axis line color.

linewidth

Sets the width (in px) of the axis line.

matches

If set to another axis id (e.g. x2, y), the range of this axis will match the range of the corresponding axis in data-coordinates space.

maxallowed

Determines the maximum range of this axis.

minallowed

Determines the minimum range of this axis.

minexponent

Hide SI prefix for 10^n if|n|is below this number.

minor

The minor property is an instance of Minor.

mirror

Determines if the axis lines or/and ticks are mirrored to the opposite side of the plotting area.

nticks

Specifies the maximum number of ticks for the particular axis.

overlaying

If set a same-letter axis id, this axis is overlaid on top of the corresponding same-letter axis, with traces and axes visible for both axes.

position

Sets the position of this axis in the plotting space (in normalized coordinates).

rangebreakdefaults

When used in a template (as layout.template.layout.xaxis.rangebreakdefaults), sets the default property values to use for elements of layout.xaxis.rangebreaks.

rangebreaks

The rangebreaks property is a tuple of instances of Rangebreak.

rangemode

If “normal”, the range is computed in relation to the extrema of the input data.

rangeselector

The rangeselector property is an instance of Rangeselector.

rangeslider

The rangeslider property is an instance of Rangeslider.

range

Sets the range of this axis

scaleanchor

If set to another axis id (e.g. x2, y), the range of this axis changes together with the range of the corresponding axis such that the scale of pixels per unit is in a constant ratio.

scaleratio

If this axis is linked to another by scaleanchor, this determines the pixel to unit scale ratio.

separatethousands

If “true”, even 4-digit integers are separated.

showdividers

Determines whether or not a dividers are drawn between the category levels of this axis.

showexponent

If “all”, all exponents are shown besides their significands.

showgrid

Determines whether or not grid lines are drawn.

showline

Determines whether or not a line bounding this axis is drawn.

showspikes

Determines whether or not spikes (aka droplines) are drawn for this axis.

showticklabels

Determines whether or not the tick labels are drawn.

showtickprefix

If “all”, all tick labels are displayed with a prefix.

showticksuffix

Same as showtickprefix but for tick suffixes.

side

Determines whether a x (y) axis is positioned at the “bottom” (“left”) or “top” (“right”) of the plotting area.

spikecolor

Sets the spike color.

spikedash

Sets the dash style of lines.

spikemode

Determines the drawing mode for the spike line. If “toaxis”, the line is drawn from the data point to the axis the series is plotted on.

spikesnap

Determines whether spikelines are stuck to the cursor or to the closest datapoints.

spikethickness

Sets the width (in px) of the zero line.

tick0

Sets the placement of the first tick on this axis.

tickangle

Sets the angle of the tick labels with respect to the horizontal.

tickcolor

Sets the tick color.

tickfont

Sets the tick font.

tickformatstopdefaults

When used in a template (as layout.template.layout.xaxis.tickformatstopdefaults), sets the default property values to use for elements of layout.xaxis.tickformatstops.

tickformatstops

The tickformatstops property is a tuple of instances of Tickformatstop.

tickformat

Sets the tick label formatting rule using d3 formatting mini- languages which are very similar to those in Python.

ticklabelindexsrc

Sets the source reference on Chart Studio Cloud for ticklabelindex.

ticklabelindex

Only for axes with type “date” or “linear”.

ticklabelmode

Determines where tick labels are drawn with respect to their corresponding ticks and grid lines.

ticklabeloverflow

Determines how we handle tick labels that would overflow either the graph div or the domain of the axis.

ticklabelposition

Determines where tick labels are drawn with respect to the axis. Please note that top or bottom has no effect on x axes or when ticklabelmode is set to “period”.

ticklabelshift

Shifts the tick labels by the specified number of pixels in parallel to the axis.

ticklabelstandoff

Sets the standoff distance (in px) between the axis tick labels and their default position.

ticklabelstep

Sets the spacing between tick labels as compared to the spacing between ticks.

ticklen

Sets the tick length (in px).

tickmode

Sets the tick mode for this axis.

tickprefix

Sets a tick label prefix.

tickson

Determines where ticks and grid lines are drawn with respect to their corresponding tick labels.

ticksuffix

Sets a tick label suffix.

ticks

Determines whether ticks are drawn or not.

ticktextsrc

Sets the source reference on Chart Studio Cloud for ticktext.

ticktext

Sets the text displayed at the ticks position via tickvals.

tickvalssrc

Sets the source reference on Chart Studio Cloud for tickvals.

tickvals

Sets the values at which ticks on this axis appear.

tickwidth

Sets the tick width (in px).

title

The title property is an instance of Title.

type

Sets the axis type.

uirevision

Controls persistence of user-driven changes in axis range, autorange, and title if ineditable:trueconfiguration.

visible

A single toggle to hide the axis while preserving interaction like dragging.

zerolinecolor

Sets the line color of the zero line.

zerolinewidth

Sets the width (in px) of the zero line.

zeroline

Determines whether or not a line is drawn at along the 0 value of this axis.
