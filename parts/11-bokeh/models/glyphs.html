Glyphs#

Ofrece los elementos básicos para representar datos en gráficos, como líneas, círculos, barras y áreas.

Note

Para más información de esta sección visitar la documentación de bokeh.

Clases#

Clases implementadas en el módulo models del tipo glyphs.

Constructor

Descripción

XYGlyph(*args:Any,id:ID|None=None, …)

Clase base de glyphs con atributos de coordenadas x y y.

Áreas, líneas y rectas

HArea(*args:Any,id:ID|None=None, …)

Renderiza un área sombreada horizontalmente entre dos curvas.

HAreaStep(*args:Any,id:ID|None=None, …)

Variante de HArea con escalonamientos entre los valores.

HSpan(*args:Any,id:ID|None=None, …)

Bandas horizontales de ancho infinito.

HStrip(*args:Any,id:ID|None=None, …)

Franjas horizontales de ancho infinito.

MultiLine(*args:Any,id:ID|None=None, …)

Renderiza varias líneas. Conjunto de múltiples líneas independientes.

Ray(*args:Any,id:ID|None=None, …)

Renderiza rays. Línea infinita con un punto de inicio y un ángulo de dirección.

Segment(*args:Any,id:ID|None=None, …)

Renderiza segmentos. Línea entre pares de puntos.

Step(*args:Any,id:ID|None=None, …)

Renderiza líneas de pasos. Línea escalonada entre valores, útil para series temporales.

VSpan(*args:Any,id:ID|None=None, …)

Líneas verticales de altura infinita.

VStrip(*args:Any,id:ID|None=None, …)

Franjas verticales de altura infinita.

VArea(*args:Any,id:ID|None=None, …)

Renderiza un área dirigida verticalmente entre dos secuencias de igual longitud de coordenadas y con las mismas coordenadas x.

VAreaStep(*args:Any,id:ID|None=None, …)

Renderiza un área sombreada verticalmente entre dos curvas. of y-coordinates with the same x-coordinates using step lines.

Cónicas y curvas

Annulus(*args:Any,id:ID|None=None, …)

Renderiza annuli. Un anillo, definido por un radio interno y externo.

Annular Wedge(*args:Any,id:ID|None=None, …)

Renderiza cuñas anulares. Un sector de un anillo, definido por un ángulo inicial y final.

Arc(*args:Any,id:ID|None=None, …)

Renderiza arcs. Un arco de círculo definido por un centro, radio y ángulos de inicio y fin.

Bezier(*args:Any,id:ID|None=None, …)

Renderiza curvas de Bezier. Una curva de Bézier definida por puntos de control.

Circle(*args:Any,id:ID|None=None, …)

Renderiza marcadores de círculo. Un círculo simple definido por su radio.

Ellipse(*args:Any,id:ID|None=None, …)

Renderiza elipses. Una elipse definida por sus ejes mayor y menor.

Quad(*args:Any,id:ID|None=None, …)

Renderiza quads alineados al eje. Cuadrilátero definido por coordenadas de cada lado.

Quadratic(*args:Any,id:ID|None=None, …)

Renderiza parábolas. Curva cuadrática definida por un punto de inicio, fin y control.

Wedge(*args:Any,id:ID|None=None, …)

Renderiza wedges. Un sector de un círculo definido por un ángulo inicial y final.

Barras

HBar(*args:Any,id:ID|None=None, …)

Renderiza barras horizontales, dada una coordenada central, altura y (izquierda, derecha) coordenadas.

VBar(*args:Any,id:ID|None=None, …)

Renderiza barras verticales, dada una coordenada central, ancho y coordenadas (arriba, inferior).

Gráficas clásicas

Line(*args:Any,id:ID|None=None, …)

Renderiza una sola línea. Línea simple entre puntos consecutivos.

Marker(*args:Any,id:ID|None=None, …)

Clase base para glyphs que son marcadores simples con línea y propiedades de relleno, ubicadas en una ubicación (x, y) con un tamaño especificado.

Scatter(*args:Any,id:ID|None=None, …)

Renderiza marcadores de dispersión seleccionados de una lista predefinida de diseños.

Imágenes

Image(*args:Any,id:ID|None=None, …)

Renderiza las imágenes dadas como datos escalares en escala de grises o en color.

ImageRGBA(*args:Any,id:ID|None=None, …)

Renderiza imágenes con valores RGBA por píxel, permitiendo transparencia.

ImageStack(*args:Any,id:ID|None=None, …)

Renderiza imágenes dadas como matrices 3D apiladas aplanando cada pila en una imagen RGBA usando un StackColorMapper.

ImageURL(*args:Any,id:ID|None=None, …)

Renderiza imágenes cargadas de URL dadas.

Texto y anotaciones

MathMLGlyph(*args:Any,id:ID|None=None, …)

Renderiza contenido matemático usando MathMLnotation.

MathTextGlyph(*args:Any,id:ID|None=None, …)

Clase base para glyphs de texto de matemáticas.

TeXGlyph(*args:Any,id:ID|None=None, …)

Renderiza contenido matemático usando LaTeXnotation.

Text(*args:Any,id:ID|None=None, …)

Renderiza texto en una ubicación específica.

Polígonos

Block(*args:Any,id:ID|None=None, …)

Renderiza regiones rectangulares, dada una coordenada de esquina inferior izquierda, ancho y altura.

HexTile(*args:Any,id:ID|None=None, …)

Renderiza baldosas horizontales en una cuadrícula hexagonal regular.

MultiPolygons(*args:Any,id:ID|None=None, …)

Renderiza varios MultiPolygon.

Ngon(*args:Any,id:ID|None=None, …)

Renderiza polígonos regulares de n-lados.

Patch(*args:Any,id:ID|None=None, …)

Renderiza un solo patch. Un solo polígono definido por una secuencia de puntos.

Patches(*args:Any,id:ID|None=None, …)

Renderiza varios patches. Conjunto de múltiples polígonos independientes.

Rect(*args:Any,id:ID|None=None, …)

Renderiza rectángulos, caracterizados por la posición central (x, y), ancho, altura y ángulo de rotación.

Clase base para todos los modelos de glyph.

Atributos#

Atributos de la clase Glyph.

Atributo

Descripción

decorations

Una colección de decoraciones del glyph, ejm. cabeza de flechas.

name

Un nombre arbitrario y suministrado por el usuario para este modelo.

syncable

Indica si este modelo debe sincronizarse de nuevo a un servidor bokeh cuando se actualiza en un navegador web.

tags

Una list opcional de valores arbitrarios, proporcionados por el usuario para adjuntar a este modelo.

Propiedades de la clase Glyph.

Descripción

El documento al que se adjunta este modelo (puede ser None).

themed_values()

Atributos#

Atributos de la clase Circle.

Atributo

Descripción

decorations

Una colección de decoraciones del glyph, ejm. cabeza de flechas.

fill_alpha

Los valores alfa de relleno para los círculos.

fill_color

Los valores de color de relleno para los círculos.

hatch_alpha

Los valores alfa del hatch para los círculos.

hatch_color

El color del hatch para los círculos.

hatch_extra

Valores adicionales del hatch para los círculos.

hatch_pattern

Los valores del patrón del hatch para los círculos.

hatch_scale

Los valores de la escala del hatch para los círculos.

hatch_weight

Los valores de peso del hatch para los círculos.

hit_dilation

El factor para dilatar el radio de hit para las herramientas de desplazamiento y toque. Hacer este valor más grande hace que las herramientas sean “más sensibles”.

line_alpha

El alfa de las líneas para los círculos.

line_cap

Los valores de cap de línea para los círculos.

line_color

Los valores de color de línea para los círculos.

line_dash

El tipo de línea para los círculos.

line_dash_offset

Las separaciones en los dashes de línea para los círculos.

line_join

Los valores de unión de línea para los círculos.

line_width

Los valores de ancho de línea para los círculos.

name

Un nombre arbitrario y suministrado por el usuario para este modelo.

radius

Los valores de radio para círculos (en unidades de datos, por defecto).

radius_dimension

Qué dimensión medir los radios del círculo a lo largo.

radius_units

Unidades para usar para la propiedad asociada: screen o data.

syncable

Indica si este modelo debe sincronizarse de nuevo a un servidor bokeh cuando se actualiza en un navegador web.

tags

Una list opcional de valores arbitrarios, proporcionados por el usuario para adjuntar a este modelo.

x

Las coordenadas x del centro de los círculos.

y

Las coordenadas y del centro de los círculos. The y-coordinates of the center of the circles.

El documento al que se adjunta este modelo (puede ser None).. The Document this model is attached to (can be None).
