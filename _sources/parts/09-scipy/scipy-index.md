# Scipy

Es una libraría que contiene algoritmos matemáticos, entre los que están integrales, álgebra lineal, estadística, optimización. Está construido sobre _numpy_. Es necesario instalarlo e importarlo.

Para utilizar `scipy` es necesario instalarlo. Desde la terminal usar:
```
# Con pip
pip install scipy

# Con conda
conda install scipy
```

Una vez instalado se debe de importar, se recomienda importar los módulos individualmente en lugar de toda la librería:
```python
# Importar scipy
from scipy import module_name
```
- _module_name_ es el nombre del módulo que se desea importar.

:::{warning}
En este sitio no se recopilan todos los módulos de _SciPy_. Para más información visitar la [documentación](https://docs.scipy.org/doc/scipy/reference/) y [guía de usuario](https://docs.scipy.org/doc/scipy/tutorial/index.html) de _scipy_.
:::
